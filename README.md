
# Password Input Lab

## Description
This project is a React application that demonstrates event handling using a password input and a submit button.

## Features
- Password input field
- Detects when a user types in the password field
- Detects when the mouse enters the submit button
- Detects when the mouse leaves the submit button
- Displays event messages in the browser console

## Components

### App
The main component that displays the PasswordInput and SubmitButton components.

### PasswordInput
Displays a password input field and uses the onChange event to detect typing.

### SubmitButton
Displays a button labeled "Submit Password" and uses onMouseEnter and onMouseLeave events to detect mouse movement.

## Technologies
- React
- JavaScript
- JSX
- Vite

## Installation

Install dependencies:

npm install

Start the development server:

npm run dev

## Testing

Run the automated tests:

npm test -- --run
